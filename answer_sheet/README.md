
# 答题卡自动阅卷系统

基于 OpenCV 的答题卡（Bubble Sheet）自动识别与评分程序，可对扫描后的答题卡图像进行透视校正、气泡检测与答案比对，自动计算得分。

## 功能特性

- **透视校正**：自动检测答题卡四角，执行四点透视变换，将倾斜拍摄的答题卡校正为正视图
- **气泡检测**：基于 Otsu 阈值分割与轮廓分析，精准定位每个选项气泡
- **自动评分**：内置答案键（Answer Key），逐题比对并计算得分百分比
- **可视化结果**：用绿色标记正确选项，红色标记错误选项，并在图像上叠加显示最终得分

## 环境依赖

| 依赖包 | 版本要求 | 安装方式 |
|--------|---------|---------|
| numpy | >= 1.19 | `pip install numpy` |
| opencv-python (cv2) | >= 4.5 | `pip install opencv-python` |
| imutils | >= 0.5 | `pip install imutils` |
| argparse | 标准库 | 无需额外安装 |

> **注意**：Windows 用户若安装 `opencv-python` 遇到依赖问题，可尝试 `pip install opencv-python-headless`。

## 使用方法

### 命令行参数

| 参数 | 简写 | 是否必填 | 说明 |
|------|------|---------|------|
| `--image` | `-i` | 是 | 输入答题卡图像的路径 |

### 运行示例

```bash
python get_answer.py -i exam_image.jpg
```

程序将依次显示以下中间处理图像（按任意键切换）：

1. **blurred** — 高斯模糊处理结果
2. **edged** — Canny 边缘检测结果
3. **contours_img** — 轮廓检测结果
4. **warped** — 透视校正后的答题卡
5. **thresh** — Otsu 阈值二值化结果
6. **thresh_Contours** — 气泡轮廓检测
7. **mask** — 每个气泡的掩膜（逐题显示）

最终显示原始图像与标注结果图像，并在控制台输出得分。

## 答案键配置

程序内置了 5 道题的标准答案，位于 `ANSWER_KEY` 字典中：

| 题号 | 0 | 1 | 2 | 3 | 4 |
|------|---|---|---|---|---|
| 正确答案 | B | E | A | D | B |

> 答案索引对应关系：0→A, 1→B, 2→C, 3→D, 4→E。如需修改答案，直接编辑 `ANSWER_KEY` 字典即可。

## 算法流程

```
输入图像
  │
  ▼
灰度化 → 高斯模糊 → Canny 边缘检测
  │
  ▼
轮廓检测 → 近似多边形 → 提取答题卡四角
  │
  ▼
四点透视变换（校正倾斜）
  │
  ▼
Otsu 阈值二值化
  │
  ▼
气泡轮廓检测 → 尺寸过滤（宽高比 0.9~1.1，边长≥20）
  │
  ▼
按行排序（每行 5 个选项）→ 逐题计算气泡填充量
  │
  ▼
与答案键比对 → 计算得分 → 可视化标注
```

## 输出说明

- **控制台输出**：`[INFO] score: XX.XX%` 显示最终得分
- **图像标注**：
  - 🟢 绿色轮廓 → 答对的题目
  - 🔴 红色轮廓 → 答错的题目
  - 图像左上角叠加显示得分百分比

## 注意事项

1. 输入的答题卡图像应清晰、光照均匀，避免严重阴影或反光
2. 答题卡需为标准的 5 题 × 5 选项布局（可根据实际调整 `ANSWER_KEY` 和排序逻辑）
3. 程序中的气泡过滤参数（`w >= 20, h >= 20, ar >= 0.9, ar <= 1.1`）可根据图像分辨率微调
4. 所有 `cv_show()` 调用会弹出中间结果窗口，生产环境可注释掉以提升运行速度
